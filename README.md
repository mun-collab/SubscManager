# 【提出課題】サブスク・定期支出整理アプリ（SubscManager）

## 1. コンセプトシート
* **アプリ名:** SubscManager（サブスクマネージャー）
* **コンセプト:** 毎月支払っている定期支出を可視化し、無駄な出費や解約忘れを防ぐCLIアプリ
* **作ろうと思った理由:** 動画配信サービスや学習ツールの無料体験・月額契約が増え、どれにいくら払っているか把握できなくなり、無駄な支払いや解約忘れが発生したため。

---

## 2. ペルソナ
* **名前:** 鈴木 健太
* **年齢:** 21歳
* **職業:** IT系専門学校生
* **趣味:** 動画鑑賞、プログラミング学習
* **困っていること:** 動画サービスや開発用APIツールなど、複数のサブスクに入りすぎて毎月の合計金額が分からない。無料体験期間が終わった後の自動更新を解約し忘れて出費してしまう。
* **利用目的:** 契約中のサブスクと月額料金を一元管理し、支払合計額や解約予定を簡単に把握したい。

---

## 3. ユーザーストーリー
1. **学生として、** 契約したサブスク名・月額料金・支払日（更新日）を登録したい。**なぜなら、** 契約内容を忘れないようにするため。
2. **学生として、** 登録しているサブスクの一覧と月額合計を表示したい。**なぜなら、** 毎月いくら使っているかを把握するため。
3. **学生として、** 不要になったサブスクを削除したい。**なぜなら、** 解約したサービスを出費計算から除外するため。
4. **学生として、** 更新日が近いサブスクの警告メッセージを表示したい。**なぜなら、** 解約忘れによる自動更新・不要な支払いを防ぎたいから。

---

## 4. 機能一覧

| No. | 機能名 | CRUD/種別 | 概要 |
| :--- | :--- | :--- | :--- |
| 1 | サブスク登録 | Create | サービス名、月額料金、カテゴリ、更新日を入力して保存 |
| 2 | サブスク一覧表示 | Read | 登録されているサービス一覧を出力 |
| 3 | サブスク情報更新 | Update | IDを指定して料金や更新日などの変更を行う |
| 4 | サブスク削除 | Delete | IDを指定して解約・不要になったサービスをデータから削除 |
| 5 | 月額合計算出 | Read（拡張） | 登録データから毎月の支払合計額を自動計算して表示 |
| 6 | 更新日通知機能 | Read（拡張） | 一覧表示時に、更新日が近い（例: 3日以内）サービスに警告（⚠️）を表示する |

---

## 5. データ設計

| 項目名 | データ型 | 内容 | 例 |
| :--- | :--- | :--- | :--- |
| `id` | int | 管理番号 | 1 |
| `name` | String | サービス名 | Netflix |
| `price` | int | 月額料金（円） | 1490 |
| `category` | String | カテゴリ | 動画 / 学習 / 生活 |
| `renewalDay` | int | 毎月の更新日 | 15（毎月15日支払い） |

## 7. フローチャート（処理の流れ）

```text
[開始]
  ↓
[メニュー表示 (1:登録 2:一覧 3:更新 4:削除 0:終了)]
  ↓
[番号を入力]
  ├─ 1: 登録画面へ → 入力データをリストへ追加

  ├─ 4: 削除画面へ → ID指定してリストから削除
  └─ 0: アプリ終了
  ↓
[メニューに戻る] （0を選択するまで繰り返し）
